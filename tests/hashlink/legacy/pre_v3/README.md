# Pre-v3 HashLink tests

These files are archived pre-v3 tests. They are intentionally outside the default HashLink v3 hxml/CTest gate and are not maintained as compatibility tests.

Use `tests/hashlink/hashlink_tests.hxml` for the v3 runtime semantic suite and `tests/hashlink/v3/hashlink_v3_smoke.hxml` for the v3 smoke gate.
